   Facendo uso della regola di Elmore per stimare la costante dominante ai nodi A e B si ottiene:

           τA = (RDR + RI )CI + (RDR + RI )(CI + CB ) + (RDR + 2RI )(CI + CA ) = 696[ps]

           τB = (RDR + RI )CI + (RDR + RI )(CI + CA ) + (RDR + 2RI )(CI + CB ) = 714[ps]
   I ritardi al 90% della escursione di segnale sono quindi TA =2.3τA =1.6ns e TB =2.3τB =1.64ns.
