B) Per il sistema in forma di stato

                           ẋ 1 (s)   = x2 (t)
                           ẋ2 (t)    = −2 cos(x1 (t)) − 3x2 (t)2 + 4u(t)
                             y(t)     = x1 (t)

   b.1) Si determinino i valori dell’ingresso ū per cui il sistema ammette punti di equilibrio.
   R. Ponendo a zero la derivata, si ha

                                                x̄2 = 0
                                           cos(x̄1 ) = 2ū

e dunque ammette punti di equilibrio se |ū| ≤ 21
   b.2) Per ū = 0 si determini la forma di stato del sistema linearizzato in uno dei punti di
equilibrio (scelto dallo studente) e se ne valuti la stabilità.




   R: Per ū = 0 i punti di equilibrio sono x̄2 = 0, cos(x̄1 ) = 0, ovvero x̄1 = π2 + kπ, con k
intero. Il sistema linearizzato è
                                                        
                                         0       1          0
                             ż =            k       z+         v
                                     −2(−1)
                                                0          4
                             q =      0 1 z

Per k è pari, la matrice del sistema linearizzato ha due autovalori immaginari e dunque
non si può dire nulla riguardo al punto di equilibrio, se k è dispari, un autovalore ha
parte real positiva e il punto di equilbrio è instabile.
