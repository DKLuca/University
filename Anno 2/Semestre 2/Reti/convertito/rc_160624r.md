1. (2 punti) Cosa significa DHCP? A cosa serve? Quali dati fornisce?

Dynamic Host Configuration Protocol
Serve per fornire ai client i parametri di collegamento alla rete IP:
    - indirizzo IP
    - netmask
    - indirizzo IP del default gateway
    - indirizzo IP del DNS
