Domanda

Uscita di un filtro reale ad un segnale sinusoidale x(t) = V0 cos(2πf0 t+ϕ), t ∈ I, con dimostrazione del
risultato in forma unificata. Calcolare l’uscita y(kT ), ottenuta dall’ingresso x(kT ) = cos(2πf0 kT +π/6)
mediante la relazione
                                                +∞
                                                X
                                      y(kT ) =      αh x(kT − hN T ),
                                                  h=0

con 1/T = 44100 Hz, f0 = 882 Hz, N = 8000, α = 0.2.


Svolgimento seconda parte

La relazione
                                                  +∞
                                                  X
                                     y(kT ) =           αh x(kT − hN T ),
                                                  h=0

corrisponde ad un filtro (l’uscita è ottenuta come una combinazione lineare di valori passati e del
valore presente dell’ingresso). La risposta impulsiva del filtro è l’uscita all’impulso δZ(T ) (kT ),

                                                +∞
                                                X
                                   h(kT ) =           αh δZ(T ) (kT − hN T ).
                                                h=0

Dunque h(kT ) = αh /T per kT = hN T, h ≥ 0, e 0 altrove. Si ottiene dunque, essendo |α| = 0.2 < 1,
                                        +∞
                                        X                               1
                              H(f ) =         αh e−j2πf hN T =                     .
                                                                 1 − αe−j2πf N T
                                        h=0

Sostituendo i valori di f0 , N, T, si ottiene H(f0 ) = 1/(1 − α) = 1/0.8 = 1.25, reale, per cui l’uscita del
filtro alla sinusoide di ingresso è

                                    y(kT ) = 1.25 cos(2πf0 kT + π/6).
