Curve in Rn
Sia [a, b] un intervallo di R con −∞ < a < b < +∞. Sia n ≥ 2.
Definizione
Si chiamano curve in Rn le funzioni continue
                    φ : [a, b]   → Rn
                          t      7→ φ(t) = (φ1 (t), φ2 (t), ..., φn (t))

nel senso che ogni funzione componente φi : [a, b] → R è continua.

     C ([a, b]; Rn ) è l’insieme delle curve in Rn
     l’immagine φ([a, b]) si chiama sostegno o traccia di φ
     φ(a) è il primo estremo
     φ(b) è il secondo estremo
     φ si dice chiusa se φ(a) = φ(b)
     φ si dice semplice se, comunque presi due punti distinti t1 e t2 di [a, b], di
     cui uno almeno interno ad [a, b], risulta φ(t1 ) ̸= φ(t2 ).
