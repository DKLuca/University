Definizione (Definizione di continuità)
Siano (X , dX ) e (Y , dY ) spazi metrici.
Una funzione f : X → Y si dice continua in un punto x0 ∈ X se

      ∀ ε > 0, ∃ δ > 0   tale che ∀x ∈ X :    dX (x, x0 ) < δ ⇒ dY (f (x), f (x0 )) < ε.

Si dice inoltre che f è continua su un insieme D ⊆ X se è continua in ogni punto di D.

(Nel caso X = Y = (R, |·|) questa coincide con la definizione classica.)

Proposizione
f : X → Y è continua in x0 ∈ X se e solo se per ogni successione (xh ) tale che xh → x0 si
ha f (xh ) → f (x0 ).

La dimostrazione si basa sul teorema dei limiti mediante successioni.

Continuità uniforme e Lipschitziana


Definizione (Continuità uniforme)
Siano (X , dX ) e (Y , dY ) spazi metrici.
Una funzione f : X → Y si dice uniformemente continua su un insieme D ⊆ X se

     ∀ ε > 0, ∃ δ > 0   tale che ∀x, y ∈ D :   dX (x, y ) < δ ⇒ dY (f (x), f (y )) < ε.

È immediato osservare che se f è uniformemente continua su D, allora è continua su D.

Definizione (Lipschitziana)
Siano (X , dX ) e (Y , dY ) spazi metrici.
Una funzione f : X → Y si dice lipschitziana su un insieme D ⊆ X se esiste una costante
M > 0 tale che
                          dY (f (x), f (y )) ≤ M dX (x, y ), ∀ x, y ∈ D.

Si hanno le implicazioni:

           Lipschitziana    =⇒    uniformemente continua      =⇒      continua.

Come calcolare i limiti per funzioni reali di più variabili

Osservazione preliminare. Sia f : A ⊂ Rn → R e sia x0 un punto di accumulazione di A.
Supponiamo che esista limx→x0 f (x) =: ℓ ∈ R. Allora: ogni restrizione di f per la quale
abbia senso calcolare il limite per x → x0 ha lo stesso limite.
Strategia conseguente:
• se riesco a individuare una restrizione di f che non ha limite per x → x0 , oppure due
restrizioni di f che hanno limiti diversi per x → x0 , allora deduco che f non ha limite per
x → x0 ;
• se, per x → x0 , una o più restrizioni producono il limite ℓ, allora congetturo che f abbia
limite ℓ e lo verifico utilizzando la definizione di limite.
• Ad esempio se n = 2, per la verifica di un limite si possono usare anche le coordinate
polari. Ad esempio se devo verificare che il limx→0 f (x) = 0 (e posso sempre, o quasi,
ridurmi in questa situazione attraverso una traslazione) se scriviamo f in coordinate
